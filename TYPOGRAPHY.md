# Context before type / Rams × NYCTA

The first typographic question is what someone must find or compare. This is
Dr Non's practical interpretation of Robert Bringhurst, *The Elements of
Typographic Style*, supplied second edition / 1997 printing, selected close
reading. The operative laws remain RAMS-DESIGN-DNA §2 and §11, with NYCTA
wayfinding roles unchanged. This is not official transit or Rams guidance.

## Apply it here

1. Start with the sanctioned functional grotesque and existing scale. The
   Helvetica Neue / Helvetica / Arial stack is the house voice; do not import
   an editorial serif or novelty display face to make a board “human”.
2. Proof actual station names, route identifiers, dates, units, errors and
   comparison columns. Test 0/O and 1/I/l at the intended viewing distance.
   Use supported tabular figures where values align, not by habit in all prose.
3. Test size, measure, leading and spacing as one system. A 9px metadata token
   does not become readable merely because tracking is wide. Do not demote
   essential decisions or explanations into micro-labels to preserve density.
4. Latin uppercase and tracking do not apply blindly to Thai/CJK. Missing
   scripts require a coherent coverage plan and documented scoped exception;
   do not mix unrelated glyphs within a word or silently change the family law.
5. Work within §11's sanctioned density and width knobs. If they cannot meet
   the reader's task, show the failed specimen and request an explicit exception.
6. Render phone width, enlarged text and blocked fonts. Check emphasis using
   available cuts, glyphs, long labels, hierarchy and palette contrast. Keep
   route/state meanings stable. Mark fluent-reader review pending when absent.

## Receipt before a type change

Reader / act / viewing distance; real text and scripts; family and actual cuts;
licence and fallback; alternative rejected with observed reason; size + leading
+ measure; proof conditions and failures; scoped approvals; human task test
and fluent-language review performed or pending.

Do not ship unreadable essential text because a style auditor passed. This
guide is a human proof layer, not a new automated check or permission to remove
house constraints. Familiar typography can be excellent; rarity is not craft.
